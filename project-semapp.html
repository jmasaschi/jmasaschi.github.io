Project 03 / The Semapp Project

Something experimental.

Learning more about nextjs, vercel, and supabase.

This is the project I have been working on in my senior seminar class. The project explores modern web technologies and frameworks mentioned above.

The idea is to make an app that greek orgs can use to keep track of philanthropy goals. The data is stored in supabase.

Connecting the database to the frontend is nextjs. Nextjs breathes life into the project and creates the necessary functionality.

Tying everything together is vercel, which deploys the app and makes it accessible to users.
